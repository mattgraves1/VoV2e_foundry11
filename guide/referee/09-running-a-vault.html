Generate Vault builds a whole vault for you: a journal with a page for every room, an encounter table for every level, and if you like a hex Scene for every level. Its rooms are not filled until you choose, so you can roll a room when the party walks into it. Only you can see the journal, its buttons and the map pins.

Generating a vault

Run Generate Vault from the Vaarn Macros compendium (chapter 7). Every field and button has a hover tip. The fields are:

  • Setting: Module Default grows vaults like the book's. Randomize rolls the shape rules too. Any setting saved in this world is listed after these. Each run uses a new seed, so the same setting grows a different vault each time.
  • Vault code: paste a code to grow that exact vault again. A code beats the Setting.
  • Journal name: leave it blank to name the journal after the vault's Original Function.
  • Shafts can be obstructed: lets the shafts between levels roll an obstruction, the way corridors do. The book only obstructs corridors, so leave this off unless you want it.
  • Save code as: type a name and click Save Setting to keep the Vault code's rules, without its seed, in the Setting list for every GM of the world.

Click Generate for the journal alone, or Generate with Scenes to make a Scene for each level as well. A card whispered to you links the journal, gives the room and level count, and gives the vault's code.

Advanced options: the Vault Settings Tuner

Advanced options... opens the Tuner. It has every rule the vault grows by, with a preview of the result that redraws as you change them. You don't need it to run a vault; use it when you want a different kind of vault.

  • Size: grow by the roll table until the vault stops or reaches the Room cap, or grow an exact number of Rooms per level and Levels.
  • Connection roll: how many exits each room rolls for, and how often an exit is a shaft down.
  • Shape rules: long straight corridors, loops against dead ends, rubble, and symmetry.

A line under the preview counts the rooms, levels, loops and dead ends. A vault with more than one level gets a button for each level, to preview it. New seed keeps the rules and grows a new vault. Randomize rolls new shape rules. Module Default puts everything back. To start from a vault you already have, paste its code into Load a code and click Load. The Tuner has its own Save setting, Generate and Generate with Scenes buttons, and its own Journal name box.

The journal

The Overview page has the Vault Entrance, the Tunnels and the Original Function, rolled from the book's tables. Next come the levels: rooms per level, the entrance, the shafts, any obstructed passages, and a link to each level's encounter table. The vault's code is at the bottom.

Each room has its own page, named by level and number (L1 Room 4). It shows the room's shape, floor and walls, its depth, its d12 type (uninhabited, lair, treasure, lair and treasure, or special), and its contents. Every exit is a link to the room it leads to. The entrance room says so.

About 1 corridor in 12 is obstructed. An obstruction has its own page, linked from the rooms at both ends, with the book's Obstacle and Effect. If an obstacle is a hazard, its page has the hazard buttons from chapter 3.

Filling rooms as the party arrives

Nothing is made until you ask for it. A lair names its creature from the start, since the level's encounter table is built from it, and is marked not yet spawned. Treasure and special rooms are marked not yet rolled or not yet created. A room's page has a button for each part left to do:

  • Spawn the lair (Depth N) makes the lair's creatures in Generated Creatures.
  • Create the treasure room (Depth N) makes a container of loot in the Actors directory. Players can't see it until you give them access.
  • A special room offers the follow-up it needs, such as Create the book. A weapon, drug, mutation or other item goes in a GM-only container. A daemon goes in Generated Creatures. An oracle, shrine or anomaly is written straight onto the page.

The result is written onto the page, linked to what it made, and the button goes away. Clicking twice does nothing extra. To fill everything ahead of time, use Roll every room or Roll level N on the Overview.

Encounters

Each level has an encounter table, L1 Encounters and so on. It is made from the creatures in that level's lairs, and Sentry Turrets if a room has them. A level with fewer than six is topped up to six from the book's Lair Rooms table for its depth. Its Roll an encounter button rolls the table and offers Spawn one of the creature it names.

To have the Exploration Clock use the table, tell the system which level the party is on:

  • click The party is on this level: record it on the level's encounter page, or
  • pick the level from Party location in the clock window, shown while Where is Vault. It lists the current vault's levels. Other vault... widens the list to every vault, and Clear unsets it, or
  • activate the level's Scene.

After that, any Encounter the clock rolls in a Vault, whether from a turn or a night without a secure campsite, names a creature from that level's table and adds a Spawn one button to the card. An Omen names the creature whose signs the party finds. When the party is done with a vault, file its journal in a folder called Explored Vaults and it drops off the Party location list.

Scenes

Generate with Scenes makes one hex Scene per level, in a Vault Scenes folder. To add Scenes to a vault made without them, click Make a Scene per level on its Overview. (A vault made before Scenes existed has to be generated again.)

  • The map is a plain outline of the rooms and corridors. Its walls and doors are real, so tokens can't walk or see through them.
  • The Scene starts dark with fog on, so players only see what their tokens can see. Give their tokens a light source or vision.
  • Each room has a map pin linked to its page, and so does each obstructed corridor: a hazard pin named for the obstacle, halfway along it. Only you see the pins, and they show even where a selected token cannot see.
  • Seeing the pins: Foundry shows pins only while the Journal Notes tool (the bookmark icon, last in the left toolbar) is active. To keep them on with any tool, click Toggle Notes Display in that tool's options.
  • Pin to page: double-click a pin to open its room. Page to pin: in the vault journal, right-click a room in the page list and choose Jump To Pin; the map pans there. It works on the Scene you are viewing.
  • New Scenes are not active and not in the navigation bar. Activate one when the party goes in. Level 1 starts at the entrance, and each lower level starts where the shaft lands.

Activating a level's Scene also records that level as the party's location, so its encounter table is used.

Try it

  1. Run Generate Vault, leave Setting on Module Default, and click Generate with Scenes. Open the journal from the whispered card.
  2. Open a lair or treasure room's page and click its button. Find what it made.
  3. Open L1 Encounters, click Roll an encounter, then Spawn one.
  4. Activate the level 1 Scene from the Vault Scenes folder. Open the Exploration Clock, set Where to Vault, and check that Party location names that level.
  5. Click Travel to another location until a turn rolls an Omen or an Encounter, and read the creature it names on the whispered card.
